# esc-stop

`ESC` 键 = 终止当前生成（Claude Code 风格）。当前会话在生成中时按 ESC 立即取消；
打开的弹层/命令菜单/`@` 补全仍然优先响应 ESC（先关弹层，再按一次才停）。

## 用法

装好后直接按 `ESC` 即可，无需配置。条件：

- 当前显示的会话正在生成（`running`）
- 没有打开的弹层/菜单（它们会先消费 ESC 关闭自己）
- 不处于输入法组合输入中

## 工作原理

- 纯浏览器插件：监听 `window` 的 `keydown`（冒泡阶段，不拦截）
- 复用官方 Stop 按钮的同一路径：`Session.cancel()`（失败落到 UI 的 promptError 通道）
- 弹层优先：composer keymap 对被消费的 ESC 调用 `preventDefault`，未消费的 ESC 才是停止手势
- 当前会话 = UI 当前选中会话（与侧栏高亮同一个数据源）

## 限制

- 只在"有内容在生成"时生效（空闲时按 ESC 无操作）
- 子代理一次性地址不可取消（与官方 Stop 按钮一致，会报错提示）
- 若某个弹层在 ESC 时未 preventDefault，会出现"同时关弹层 + 停止生成"——大部分弹出层已正确消费
