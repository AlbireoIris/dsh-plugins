# global-file-ref

输入框敲 `@` 时的**全盘路径补全**：所有盘符自动枚举，shell 式一层 Tab 补全，
上次使用的路径置顶。与官方 `@` 文件引用源（ui-reference）共存——它管会话工作区，
本插件管全盘。

## 用法

在输入框里输入（`@` 前留空格/标点即可触发，遵循官方词边界规则）：

- `@` → **最近使用**（最多 8 条，置顶）+ **所有盘符**（C:\ D:\ E:\ …）
- `@C:\` → `C:\` 直接子项（目录在前，文件在后，限制 200 条）
- `@C:\Us` → 当前层匹配 "Us" 的子项（包含匹配、不区分大小写）
- `@C:\Users\Iris\` → `Iris` 目录的直接子项（一层，不递归）
- 选中文件 → 插入 `@路径`（空格用 `@"path"`）；选中目录 → `@路径\` 可继续接续输入补全

**一级规则的完整语义**：候选永远是"当前路径段的直接子项"——不会递归整棵子树；
层层推进靠尾斜杠：选完目录后路径带 `\`，继续敲就是在下一层补全。

## 工作原理

- 宿主 `POST /dsh/ref-list`：纯只读列目录（无递归），盘符用 `A:-Z:` 探测存在性；
  每次请求上限 200 条，无任何写入/删除端点（与官方工作区引用源的写能力不同）。
- 客户端注册 `@` 触发源（name `global-file`，order 0 —— 在官方 `reference` 源上方），
  与官方源共存（多源 adjudication）；`onPick` 记录"最近使用"（localStorage，按路径去重）
  并在下次 `@` 置顶显示；插入格式与官方一致（`formatFileMention` 规则）。

## 与官方的关系

- 官方 `ui-reference`（`@` 源 name `reference`）：继续提供会话工作区文件 + 会话引用候选。
- 本插件：只在最上方加"最近使用 + 全盘"组；两者的候选在同一个 `@` 菜单里并列。

## 安装

见仓库根 README「安装插件到 dsh web」。要求 dsh web 已启用输入触发管线
（`ui-input-trigger` 在默认 web bundle 中）。本插件宿主无配置项。
